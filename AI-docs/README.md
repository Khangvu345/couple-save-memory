# 🗂️ AI-docs — Tài liệu dự án

Thư mục này chứa các tài liệu được tạo và duy trì bởi AI trong quá trình phát triển dự án **"Bộ phim của chúng ta"**.

## Danh sách tài liệu

| File | Mô tả |
|------|-------|
| [`CHANGELOG.md`](./CHANGELOG.md) | Lịch sử các thay đổi theo session, bao gồm bug fix và feature mới |

## Quy ước

- Mỗi session làm việc với AI sẽ được log vào `CHANGELOG.md`
- Format ngày: `YYYY-MM-DD`
- Mỗi thay đổi ghi rõ: file bị ảnh hưởng, vấn đề gặp phải, cách giải quyết
